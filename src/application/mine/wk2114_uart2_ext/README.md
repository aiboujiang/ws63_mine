# WK2114 UART2 扩展模块（从 0 重构）

本模块依据 WK2114 应用笔记优先实现，使用 UART2 作为主口接入 WK2114。

## 接线约定

1. UART2 TX -> WK2114 MRX
2. UART2 RX -> WK2114 MTX
3. GPIO10 -> WK2114 RST（上拉，低电平复位有效）
4. GPIO13 -> WK2114 IRQ（上拉，低电平有效）

## 初始化流程

1. 上电后硬件复位：高10ms -> 低10ms -> 高20ms。
2. 主口发送 `0x55`，等待 100ms 完成波特率自适应锁定。
3. 读取固定寄存器 `GENA`，默认值应为 `0xF0`。
4. 对 `GENA` 做写读回校验，确认读写链路都正常。

## 子串口配置流程

1. 切 `SPAGE=1`，写 `BAUD1/BAUD0/PRES`。
2. 切 `SPAGE=0`，写 `SCR/FCR`。
3. 使能 `GENA` 对应子串口时钟位。
4. 关键寄存器均执行读回校验。

## 说明

1. 本重构版本不包含 OLED 逻辑。
2. 已保留 IRQ 低电平触发中断处理与日志。
