# WK2114 UART2 扩展模块

本模块实现 WK2114 应用笔记功能实现，使用 UART2 作为内联接口 WK2114。

## 接线约定

1. UART2 TX -> WK2114 MRX
2. UART2 RX -> WK2114 MTX
3. GPIO10 -> WK2114 RST（低电平复位有效）
4. GPIO13 -> WK2114 IRQ（低电平有效）

## 初始化步骤

1. 上电硬件复位（10ms 拉高 -> 拉低10ms -> 拉高20ms）
2. 发送 0x55，等待 100ms 完成内部自适应波特率
3. 读取固定寄存器 GENA（默认值应为 0xF0）
4. 对 GENA 寄存器写入验证，确保读写路径正常

## 子串口配置流程

1. 设置 SPAGE=1，写 BAUD1/BAUD0/PRES
2. 设置 SPAGE=0，写 SCR/FCR
3. 使用 GENA 寄存器对应子串口使能
4. 关键寄存器执行读写验证。
